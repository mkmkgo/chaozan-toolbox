链接导入

粘贴公众号文章链接或任意网页链接，抓取其中的图片。

受浏览器跨域限制，多数站点无法直接抓取。建议改用「复制图片后 Ctrl+V 粘贴」。

快速入门

  1. 添加图片：点顶栏「添加图片」，或直接拖拽 / Ctrl+V 粘贴，支持一次多选。
  2. 换模板：点「换模板」，按图片张数筛选，33 套模板随点随换。图片多于模板位数时会自动重复拼接。
  3. 调参数：右栏改圆角、阴影、行间隔、内边距、背景，预览区实时生效。
  4. 选中积木块：点预览里的任意一行，出现绿框和 ↑ ↓ × 浮动条，可上下移动或删除该块。
  5. 导出：点「复制导出」，然后到公众号编辑器里 Ctrl+V；或点左侧「长图」导出图片。

排版提取

在公众号文章页面全选（Ctrl+A）复制正文，粘贴到下面，就能把对方的排版搬过来。

学习教程

1. 快速上手

添加图片 → 换模板 → 调参数 → 复制导出。四步就能做完一篇图文。

2. 怎么添加图片

点顶栏「添加图片」可一次多选；也可以把图片直接拖进左侧虚线框，或在页面上按 Ctrl+V 粘贴截图。

3. 换模板与图片数量

模板按「能放几张图」分类。图片比模板位数多时，模板会整组重复拼接；少的时候空位自动隐藏，剩下的图会撑满整行。

4. 积木块是什么

点预览里的任意一行会出现绿框和 ↑ ↓ × 浮动条，可以整块上移、下移或删除。这是调整图文顺序最快的方式。

5. 图片圆角

「全部」滑块会同时改四个角；想单独调某个角，用下面的左上/右上/左下/右下。

6. 图片阴影

上下偏移控制阴影往下还是往上，模糊越大越柔和，颜色建议比背景深一点的灰。

7. 行间隔

控制每一行图片上下的留白，范围 0–200px。想做出「呼吸感」排版，一般 20–40 就够。

8. 预留空行

在排版最上面或最下面留一个空行，方便复制到公众号后再补标题、二维码或关注引导。

9. 文章背景

可以加图片背景（自动纵向平铺）或纯色背景，还能给背景加圆角。加了背景建议同时设置内边距，不然图片会贴边。

10. 排版缩放（内边距）

给整个页面加内边距，相当于把内容往中间收。背景图铺满时特别好用。

11. 文案怎么加

「文案」里可以选最上面、最下面或图文穿插。穿插模式会按空行分组，逐段插到每行图片后面。

12. 防盗图是怎么实现的

开启后图片会被替换成同尺寸的 CSS 背景图，读者长按无法查看大图或另存。复制到公众号后依然生效。

13. 复制导出到公众号

点「复制导出」，然后打开公众号后台新建图文，在正文区域按 Ctrl+V。样式会以内联形式保留。

14. 导出长图 / 排版提取

左侧「长图」把整篇排版导成 2 倍图，适合发朋友圈。「文章复制 → 开始使用」可以把别人文章的排版粘过来直接用。
